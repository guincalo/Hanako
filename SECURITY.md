# Security

Hanako is an unofficial hobby fork, mostly written with AI coding agents. Its code has had **no security review**, and
there are **no guarantees** of any kind about fixes or response times. Do not rely on it where your
safety depends on your messenger.

## Reporting a vulnerability

- For problems in **Hanako's own features**, please use GitHub's
  [private vulnerability reporting](https://github.com/guincalo/Hanako/security/advisories/new)
  if it is available on this repository, or open an issue that says only that you have a security
  report (no details) and ask for a private channel.
- For problems that also exist in upstream **Forkgram Classic** or in official **Telegram**, report them
  to those projects instead: [Forkgram Classic](https://github.com/forkgram/forkgram-classic) and
  Telegram ([bug bounty / security@telegram.org](https://core.telegram.org/bug-bounty)).

Only the latest release is looked at.
