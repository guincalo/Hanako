Hanako

An unofficial Telegram client for Android with Telegram’s classic interface, built on Forkgram Classic.

Download 2.04 Add to Obtainium Source on GitHub

Hanako is experimental. Most of its own code was written with AI coding agents and has had limited testing, so expect bugs and keep backups. It is not affiliated with Telegram, Forkgram or Mercurygram; please report Hanako bugs on GitHub, not to them.

Everything Forkgram Classic does, plus the following, in one settings screen.

Ghost mode

  • No read receipts, typing, online status or story views, per account
  • Exceptions for chosen chats, a quick toggle, silent sending
  • Story guard, and peeking at chats without marking them read

Privacy

  • Lock chats with biometrics and hide them
  • Streamer mode: pseudonyms, masked avatars, hidden numbers
  • Ask before sending voice, stickers, GIFs or calling

Deleted and edited messages

  • Deleted messages stay in the chat; edits keep their history
  • Media from deleted and view-once messages is kept and browsable
  • Keep rules: per chat or per person, choose what gets kept
  • A local log of when contacts were online and read your messages

Chats

  • Regex message filters
  • Chat export in Telegram Desktop’s HTML and JSON formats
  • Message shots, session backup, profile DC and registration date
  • Hide the “Send as” button

Look

  • Rin, the dark theme from Hanako 1.3, and Hanako, a light one
  • Pitch black for OLED screens, on top of any dark theme

New in 2.04

The first stable release on Forkgram Classic, out on 21 October 2026. Rin is back to how it looked in 1.3, pitch black is new, and hiding the “Send as” button works now. Read the full changelog.

Install

  1. Download Hanako-v2.04-arm64-v8a.apk from Releases and install it. Only arm64-v8a builds are published, and development builds are marked as pre-releases.
  2. Or let Obtainium keep it updated: stable releases or stable and development builds.

The package ID is moe.hanako.chan. Hanako 2.x installs as an update over Hanako 1.2 and later; make a session backup first. Hanako 1.x won’t offer the update by itself, so install it from here.
