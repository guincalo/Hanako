Hanako is an unofficial Telegram client for Android based on Forkgram Classic, which keeps Telegram's classic interface from before the "Liquid Glass" redesign.

It adds ghost mode, chat lock, kept deleted and edited messages, a local activity log, streamer mode, message filters and chat export in Telegram Desktop's format, all in one settings screen.

Usage statistics are opt-in and off by default. Hanako is not affiliated with Telegram.
